# Contact Club

Contact Club adalah aplikasi buku alamat digital untuk menyimpan dan mengelola kontak orang-orang penting dalam satu tempat. Pengguna dapat mulai menggunakan aplikasi sebagai tamu, atau membuat akun agar kontak tersimpan melalui layanan API.

## Fitur

- Tambah kontak dengan nama dan tag.
- Cari kontak berdasarkan nama.
- Edit dan hapus kontak.
- Gunakan aplikasi tanpa akun; kontak tamu disimpan di browser.
- Daftar dan masuk untuk mengelola kontak melalui API.
- Sinkronkan kontak tamu ke akun setelah berhasil masuk.
- Pilih bahasa Indonesia atau Inggris.
- Simpan sesi masuk selama satu jam atau tujuh hari dengan opsi "ingat saya".

## Teknologi

- React 18
- Vite
- React Router
- React Icons
- [Dicoding Contact API](https://contact-api.dicoding.dev/)

## Menjalankan proyek

Pastikan Node.js dan npm sudah terpasang, lalu jalankan:

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Vite di terminal.

## Perintah yang tersedia

```bash
npm run dev      # Jalankan server pengembangan
npm run build    # Buat build produksi di direktori dist
npm run preview  # Pratinjau build produksi
npm run lint     # Periksa kode dengan ESLint
```
